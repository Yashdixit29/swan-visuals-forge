# SWAN Brand Showcase

Bilkul. Tumhari images ko visual reference maan kar, aur ye clear rakhte hue ki brand ka naam sirf SWAN hai (SWAN Coffee nahi), ye prompt kisi AI website builder/coding tool mein directly use kar sakte ho:

Create a premium, modern, fully responsive and animated brand portfolio website for my own food & beverage brand called “SWAN”.

IMPORTANT BRAND RULE:

The brand name is ONLY “SWAN”.

Do NOT use “SWAN Coffee” anywhere on the website.

SWAN is a complete cafe/restaurant and food brand, not a coffee-only business.

I have provided 4 reference images. Use them ONLY as visual inspiration for the brand identity, packaging, staff uniform, display styling, premium presentation, typography feel, cleanliness and overall aesthetic. Do not simply copy the images. Create a fresh, original website design based on the same premium visual language.

WEBSITE PURPOSE:

This website should work as an official brand portfolio / company showcase website for SWAN. It should explain what SWAN is, what products it offers, its quality standards, staff, cleanliness, food philosophy, brand identity and contact/enquiry information.

DESIGN DIRECTION:

Create a bright, elegant, premium and modern interface.

Use a sophisticated light theme with:

- White

- Soft violet

- Purple

- Cyan

- Sky blue

- Soft pink

- Subtle gradients

- Very light glassmorphism

- Warm neutral accents inspired by the reference branding

Avoid an excessively dark interface.

The website should feel clean, fresh, premium, trustworthy, youthful and suitable for both university and professional environments.

Do NOT make it look like a generic restaurant template.

It should feel like a professionally established independent food brand.
